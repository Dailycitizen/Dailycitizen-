Daily Citizen V1

Know Your Rights. Know Your Power.

Daily Citizen is a Nigerian civic and legal education platform. This Netlify edition uses static HTML, CSS and JavaScript, JSON content collections, Netlify Functions and GitHub-based content publishing.

Administration

After deployment and environment configuration, open the secure admin dashboard to manage the JSON content collections.

Analytics and privacy

Live audience estimates use anonymous first-party browser and session identifiers. Raw IP addresses are not stored. Visitors may be counted as new if they clear browser storage, use another device or block analytics.

Legal information

Daily Citizen provides general educational information, not legal advice. Laws and court decisions should be checked against authoritative sources and reviewed by qualified legal practitioners.
